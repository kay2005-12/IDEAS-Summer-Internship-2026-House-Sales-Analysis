### Project Title
Data Analysis with House Sales Data

### Project Description
This project was completed as part of the IDEAS Summer Internship Program 2026.

The objective of this project is to analyze house sales data, perform data preprocessing, exploratory data analysis, feature selection, and build a machine learning model for house price prediction.

### Dataset
- House Sales Dataset (house_price_india.csv)

### Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib

### Project Tasks
1. Data Loading and Inspection
2. Data Cleaning and Preprocessing
3. Descriptive Statistics
4. Group-wise Analysis
5. Correlation Analysis
6. Feature Selection
7. Linear Regression Model
8. Model Evaluation using R² Score
9. K-Means Clustering
10. Clustering Evaluation using F1 Score and Confusion Matrix

### Results
- Linear Regression R² Score: ~0.50
- K-Means Clustering F1 Score: ~0.87
